# 表情包使用说明

## 超简单，两步搞定

### 1. 把图片拖进对应文件夹

```
stickers/
├── 害羞/     ← 丢害羞的表情包进来
├── 开心/     ← 丢开心的表情包
├── 撒娇/
├── 生气/
├── ...
```

### 2. 没了，就这样

百约自动读取，不用配置任何文件。

## 12个分类

| 打招呼 | 开心 | 害羞 | 撒娇 | 生气 | 伤心 |
|--------|------|------|------|------|------|
| 晚安 | 疑惑 | 无语 | 得意 | 摸头 | 吃瓜 |

## 支持格式

PNG / JPG / GIF / WebP / BMP

## 获取表情包

从QQ群文件下载表情包zip → 解压 → 按分类拖进对应文件夹
