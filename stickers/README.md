# 表情包使用说明

## 1. 获取表情包
从 QQ 群文件下载表情包 zip，解压到当前文件夹（stickers/）。

## 2. 配置映射
编辑 stickers.json，把图片文件名填进对应的标签数组：

{
  "害羞": ["shy_cat.gif", "blush.png"],
  "开心": ["laugh.jpg", "happy_dance.gif"],
  ...
}

## 3. 有效标签
打招呼 | 开心 | 害羞 | 撒娇 | 生气 | 伤心
晚安   | 疑惑 | 无语 | 得意 | 摸头 | 吃瓜

## 4. 百约会自动用
AI 回复中会写 [贴纸:害羞]，bot 自动从对应标签下随机抽一张图发送。

## 5. 格式支持
PNG / JPG / GIF / WebP
