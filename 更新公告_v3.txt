【百约 v3.0 更新公告】

百约QQ机器人重大更新！支持多种AI模型、表情包系统、更聪明的错误提示，还有更自然的聊天体验。


════════════════════════════════
一、新功能
════════════════════════════════

【1. 多AI模型支持】

WebUI里一键切换AI模型，不再绑定DeepSeek：

  DeepSeek    - deepseek-chat      充值10元能用很久
  OpenAI      - gpt-4o            按量付费
  硅基流动    - Qwen/Qwen3-8B      注册送额度
  智谱 GLM    - glm-4             注册送额度
  通义千问    - qwen-plus         有免费额度
  月之暗面    - moonshot-v1-8k     注册送额度
  Groq        - llama-4-scout     免费（需梯子）
  Ollama      - qwen2.5:7b        本地运行，完全免费

老用户已自动迁移，DeepSeek Key 继续用，不用重新配置。


【2. 表情包系统】

百约会根据情绪自动发表情包了！12个分类：

  打招呼 | 开心 | 害羞 | 撒娇 | 生气 | 伤心
  晚安   | 疑惑 | 无语 | 得意 | 摸头 | 吃瓜

怎么用：
  a. 打开 stickers/ 文件夹，看到12个分类文件夹
  b. 把表情包图片拖进对应文件夹
  c. 百约自动读取，不用任何配置文件
  d. 支持 PNG / JPG / GIF / WebP

表情包图片不随代码推送，需要从QQ群文件下载表情包zip。


【3. 私密模式】

支持加载私密人格文件，包含更亲密的对话内容。

  - 默认关闭，需要手动在WebUI开启
  - 创建 prompt_private.txt 写入自定义人格
  - 文件不会上传到GitHub
  - 群聊和陌生人自动使用普通人格


【4. 智能改进】

  - 精准错误提示：API没钱了直接说"余额不足"，不再显示"信号不好"
  - 消息自动拆分：AI回复自动按句子拆成2条消息，像真人连续发消息
  - 括号自动清理：AI回复中的动作描述自动过滤，对话更自然


════════════════════════════════
二、更新方法
════════════════════════════════

【新用户】

  git clone https://github.com/bailidashi/baiyue.git
  cd baiyue
  pip install websockets requests

然后从QQ群文件下载表情包zip，解压到 stickers/ 文件夹。

【老用户】

  cd baiyue
  git pull

旧配置自动兼容。新的表情包系统需要从群文件下载zip。


════════════════════════════════
三、快速上手
════════════════════════════════

  1. 打开 NapCatQQ
  2. 运行 python bot.py
  3. 浏览器打开 http://127.0.0.1:8080
  4. 填入 API Key，保存
  5. 选人格，开始聊天


════════════════════════════════
四、注意事项
════════════════════════════════

  1. 表情包图片不会通过git推送，需从QQ群文件单独下载
  2. 私密模式默认关闭，需手动在WebUI开启
  3. Ollama本地模型需先安装Ollama并拉取模型
  4. 硅基流动等国内平台的Key需在对应官网注册获取
  5. 群聊中百约只在被@或叫名字时回复
  6. 更换AI模型后如果报错，先检查API Key和余额
